# 🧠 DSA Revision Tracker

A full-stack web application designed to help students **practice, track, revise, and analyze Data Structures & Algorithms problems** in one place.

The goal of this project is to make DSA preparation more organized by keeping track of solved problems, revision progress, practice history, and overall performance.

---

## 🚀 Features

* 📊 **Dashboard** — View overall DSA progress at a glance
* 📝 **Problem Tracking** — Add and manage DSA problems
* 🔄 **Revision Tracking** — Keep track of problems that need revision
* 🎯 **Practice Mode** — Practice problems based on your preparation
* 📈 **Analytics** — Analyze solving and revision progress
* 🔐 **User Authentication** — Secure login system
* 📚 **Topic-wise Practice** — Organize problems by DSA topics
* 📱 **Responsive UI** — Works across desktop and mobile screens
* 🎨 **Modern Interface** — Clean and simple dashboard-based design

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Samir-Shaw/dsa-revision-tracker.git
```

```bash
cd dsa-revision-tracker
```

---

### 2. Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file:

```env
PORT=5000
DB_HOST=localhost
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=dsa_tracker
JWT_SECRET=your_secret_key
```

Start the backend:

```bash
npm run dev
```

---

### 3. Setup Frontend

Open another terminal:

```bash
cd frontend
npm install
```

Start the frontend:

```bash
npm run dev
```

The application will then be available through the local development URL shown by Vite.

## 📊 Main Modules

### 🏠 Dashboard

Provides a quick overview of your DSA preparation, including solved problems, pending revisions, and progress.

Manage your DSA problem collection and organize problems according to topics and difficulty.

Track problems that require revision and maintain a consistent revision cycle.

Practice DSA problems and improve problem-solving consistency.

Visualize your preparation progress and understand your strengths and areas that need more practice.

Users can create an account and securely access their personal DSA progress.
